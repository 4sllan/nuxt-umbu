Nuxt Umbu provides **seamless integration with Laravel Passport** to implement secure OAuth2 authentication in your Nuxt applications.

## Overview

Laravel Passport is a full OAuth2 server implementation for Laravel applications. Nuxt Umbu simplifies the integration by providing:

- **Token-based authentication** using OAuth2 grants
- **Multiple grant types** support (password, authorization_code)
- **Automatic token management** (refresh, expiration)
- **Two-factor authentication** support
- **Secure cookie handling** with CSRF protection
- **Server-side rendering** compatibility

## Key Features

### 🔐 OAuth2 Authentication
- Full OAuth2 implementation with Laravel Passport
- Support for password and authorization_code grants
- Automatic token refresh and expiration handling

### 🛡️ Security
- CSRF protection with secure cookie handling
- HTTP-only cookies for token storage
- Secure token transmission via headers

### 🔄 Token Management
- Automatic token refresh on expiration
- Local storage fallback for client-side

### 📱 Two-Factor Authentication
- Built-in 2FA flow support

### 🎯 Developer Experience
- Simple composable API
- Type-safe configuration
- Auto-completion and IntelliSense support

## Quick Start

```bash
# Install Nuxt Umbu
npm install nuxt-umbu

# Configure in nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-umbu'],
  
  auth: {
    provider: 'passport'
  },
  
  runtimeConfig: {
    secret: {
      client: {
        client_id: process.env.AUTH_CLIENT_ID || '',
        client_secret: process.env.AUTH_CLIENT_SECRET || '',
        grant_type: 'password'
      }
    },
    public: {
      baseURL: 'http://localhost:80' // Your Laravel API
    }
  }
})
```

## Authentication Flow

The Passport authentication flow follows these steps:

1. **CSRF Token Request** → Get CSRF cookie from Laravel
2. **OAuth2 Authentication** → Exchange credentials for access token
3. **Token Storage** → Store token securely in cookies/localStorage
4. **User Profile** → Fetch authenticated user data
5. **API Requests** → Include token in subsequent requests

## Available Composables

Nuxt Umbu provides several composables for Passport authentication:

### `useAuth()`
Main composable for authentication operations:

```typescript
const { user, loggedIn, loginWith, logout, twoFactor } = useAuth()
```

### `useAuthHeaders()`
Access authentication headers for API requests:

```typescript
const { headers } = useAuthHeaders()
```

## Configuration Options

The Passport provider supports extensive configuration options:

- **OAuth2 credentials** (client_id, client_secret, grant_type)
- **Custom endpoints** for login, logout, user profile
- **Cookie options** for secure token storage
- **Redirect URLs** for post-authentication navigation
- **2FA configuration** for two-factor authentication
